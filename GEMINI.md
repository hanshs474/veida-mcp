# Veida extension

Use the Veida tools when the user wants a picture made from a description: a product shot, an
illustration, a poster, a social image.

1. `generate_image` returns a hosted image URL. No key or account is needed; output is 1K and
   watermarked, and one call takes 40 to 120 seconds.
2. `free_tier_limits` explains what the anonymous tier allows before you promise a batch.
3. `list_models` and `browse_tools` point to the signed-in models and tool pages on
   https://veida.ai when the user needs readable text in the image, no watermark, or editing.

Name the light, the material and the composition in the prompt; that moves the result more than
adjectives do.
